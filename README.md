# Mustache

A MediaWiki extension that allows users with `editsitecss` and `editsitejs` rights to create and edit raw HTML pages in a new HTML namespace. HTML pages can be included in regular wiki pages using the `{{#html:}}` parser function.

Mustache template support existed but has been removed for security reasons: the chance of inadvertently introducing an XSS attack is too high.

For detailed usage instructions, see the [documentation page on mediawiki.org](https://www.mediawiki.org/wiki/Extension:Mustache).
